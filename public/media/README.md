# Media assets

이 폴더에는 권리를 확인한 이미지 파일만 넣습니다.

## 넣을 수 있는 이미지

- 직접 촬영했고 온라인 게시 동의를 받은 공연/팬 사진
- 사용 허가를 받은 공식 프레스 이미지
- 라이선스가 명시된 이미지

## 권장 파일명

- `hero-draag-archive.webp` — 첫 화면 배경용, 2000px 이상
- `concert-incheon-2026.webp` — 공연 허브용, 1600px 이상
- `album-black-parade.webp` — 앨범 카드용 정사각형

각 파일의 출처와 권한은 `public/media/credits.md`에 기록합니다. 앨범 커버·공식 사진은 권리 확인 전에는 저장소에 복사하지 않습니다.

현재 첫 화면은 `public/img/hero-draag-archive.webp`를 우선으로 읽도록 연결되어 있습니다. 파일이 없으면 기존 그래픽 배경으로 표시됩니다.
